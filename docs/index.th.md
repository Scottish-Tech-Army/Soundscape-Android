# Soundscape คืออะไร
Soundscape เป็นแอปฟรีแบบโอเพนซอร์สที่ใช้เสียงสามมิติเชิงพื้นที่ เพื่อช่วยให้ผู้ที่มีความบกพร่องทางการเห็นรับรู้สภาพแวดล้อมรอบตัวและเดินทางได้อย่างมั่นใจยิ่งขึ้น

แทนที่จะบอกทางเลี้ยวต่อเลี้ยว Soundscape ทำหน้าที่เหมือนประภาคารสำหรับหู ผู้ใช้จะได้ยินเสียงที่มาจากทิศทางของสถานที่จริงผ่านหูฟังสเตอริโอ ทำให้สร้างแผนที่ในใจของสภาพแวดล้อมได้ละเอียดขึ้น

- **การประกาศอัตโนมัติ** – ขณะที่คุณเดิน แอปจะบอกทางแยก ร้านค้า ป้ายรถประจำทาง สวนสาธารณะ และจุดที่น่าสนใจอื่น ๆ ที่อยู่ใกล้เคียง
- **สัญญาณเสียงนำทาง** – ตั้งจุดหมายแล้วคุณจะได้ยินเสียงเชิงพื้นที่ต่อเนื่องที่ดึงคุณไปทางนั้น เสียงจะเปลี่ยนไปเมื่อคุณหันไปในทิศทางที่ถูกต้อง
- **การรับรู้ตำแหน่ง** – แตะปุ่มเพื่อฟังว่ามีอะไรอยู่รอบตัวคุณในแต่ละทิศทาง คุณอยู่บนถนนใด หรือมีอะไรอยู่ข้างหน้า
- **เครื่องหมายและเส้นทาง** – บันทึกสถานที่โปรดและสร้างเส้นทางเดินระหว่างสถานที่เหล่านั้น แอปจะนำทางคุณไปตามเส้นทางและเลื่อนไปยังจุดถัดไปโดยอัตโนมัติเมื่อคุณไปถึง
- **ดูตัวอย่างถนน** – สำรวจพื้นที่ที่ไม่คุ้นเคยแบบเสมือนก่อนไปจริง เพื่อสร้างความมั่นใจและความคุ้นเคย

แอปยังทำงานต่อในเบื้องหลังเมื่อโทรศัพท์อยู่ในกระเป๋าเสื้อหรือกระเป๋าถือ ไม่ต้องถือไว้หรือมองหน้าจอ แอปนี้ฟรีทั้งหมด ไม่มีโฆษณาและไม่เก็บข้อมูล และรุ่น Android สามารถทำงานแบบออฟไลน์โดยใช้พื้นที่แผนที่ที่ดาวน์โหลดไว้
