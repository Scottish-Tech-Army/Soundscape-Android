# Siri の音声コマンド

iPhone では、スマートフォンに触れずに、Siri に Soundscape の操作を頼めます。たとえば、コールアウトを聞く、ルートを開始する、マーカーにビーコンを設定する、といった操作です。

Soundscape は、いつものコールアウトとビーコンの音を使って、自分の声で答えます。そのため、それぞれの音は今までどおり場所の方向から聞こえます。

音声コマンドは、スマートフォンがポケットに入っているときや、両手がふさがっているときに使ってください。Soundscape がバックグラウンドにあるときも、スマートフォンがロックされているときも使えます。コールアウトを頼んでも、アプリは開きません。

聞き取りを行うのは Siri で、Soundscape ではありません。そのため、Soundscape がマイクを使うことはなく、Bluetooth ヘッドホンの高音質も保たれます。

## 頼み方

すべてのコマンドは同じ形をしています。*「Soundscape」*、次にグループ、次にあなたの選択です。たとえば *「Soundscape 周辺 周辺」* のように言います。

グループまで言って止めることもできます。すると Siri がどの選択にするか尋ねます。つまり、各グループは音声メニューのように働きます。覚えるグループは 7 つだけです。

## 頼めること

*「Soundscape 周辺」* — 続けて *現在地*、*周辺*、*前方*、*近くのマーカー*、*ビーコンを読み上げる*、*ビーコン情報* のいずれか。

*「Soundscape ルート」* — 続けて *次のウェイポイント*、*前のウェイポイント*、*ビーコンをミュート*、*停止* のいずれか。

*「Soundscape ルート開始」* — 続けて自分のルートの名前。

*「Soundscape ビーコン」* — 続けて自分のマーカーの名前。

*「Soundscape ビーコン停止」*。

*「Soundscape 詳細」* — 続けて *無音*、*基本*、*簡略*、*詳細* のいずれか。*無音* にすると自動コールアウトはオフになります。

*「Soundscape リスト」* — 続けて *ルート*、*マーカー*、*コマンド* のいずれか。*コマンド* は、この一覧を読み上げます。

## 知っておくと便利なこと

これらのコマンドは、ショートカットアプリと、iOS の設定アプリの *Siri* にも表示されます。そこで一覧全体を確認したり、どのコマンドにも独自の言い回しを追加したりできます。
