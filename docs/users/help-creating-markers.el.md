# Δημιουργία δεικτών

Ο πιο γρήγορος τρόπος για να δημιουργήσετε έναν δείκτη είναι από την οθόνη *Δείκτες*: επιλέξτε το κουμπί *Νέο* στην πάνω δεξιά γωνία της οθόνης και, στη συνέχεια, επιλέξτε *Τρέχουσα τοποθεσία* ή ένα μέρος σε μία από τις κατηγορίες των *Κοντινές τοποθεσίες*. Μπορείτε επίσης να αποθηκεύσετε οποιοδήποτε μέρος βρίσκετε από την αρχική οθόνη, με τη γραμμή αναζήτησης, το κουμπί *Κοντινές τοποθεσίες* ή το κουμπί *Τρέχουσα τοποθεσία*. Επιλέγοντας ένα μέρος μεταβαίνετε στην οθόνη *Λεπτομέρειες τοποθεσίας*, όπου επιλέγετε το κουμπί *Αποθήκευση ως δείκτη*.

Τώρα θα έχετε την επιλογή να προσαρμόσετε αυτόν τον δείκτη. Μπορείτε να αλλάξετε το όνομα του δείκτη και επίσης να προσθέσετε ένα σχόλιο/σημείωση που θα ανακοινώνεται μαζί με τον δείκτη για να παρέχει επιπλέον πληροφορίες. Μόλις τελειώσετε, επιλέξτε το κουμπί *Έτοιμο* για να αποθηκεύσετε τον δείκτη σας.
