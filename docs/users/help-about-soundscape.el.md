# Σχετικά με το Soundscape

Το Soundscape χρησιμοποιεί καινοτόμο τεχνολογία βασισμένη στον ήχο για να βοηθήσει τους ανθρώπους να αποκτήσουν πληρέστερη αντίληψη του περιβάλλοντός τους. Αυτό κάνει τους ανθρώπους πιο σίγουρους και ικανούς να μετακινούνται αυτόνομα.

Το Soundscape βασίζεται σε αυτές τις εξαιρετικές βιβλιοθήκες και δεδομένα τρίτων. Κάντε κλικ στους συνδέσμους για να δείτε τις άδειές τους:

[©OpenStreetMap contributors](https://www.openstreetmap.org/copyright) παρέχουν όλα τα γεωγραφικά δεδομένα για τη χαρτογράφηση και τον ήχο που χρησιμοποιούνται στο Soundscape.

[©OpenMapTiles](https://github.com/openmaptiles/openmaptiles/blob/master/LICENSE.md) χρησιμοποιείται για τη δημιουργία των πλακιδίων χάρτη (map tiles) που χρησιμοποιούμε.

[Steam Audio library ©Valve Corporation](https://github.com/ValveSoftware/steam-audio) χρησιμοποιείται για τη δημιουργία του 3D ήχου και διατίθεται για χρήση υπό την [άδεια Apache 2.0](https://github.com/ValveSoftware/steam-audio/blob/master/LICENSE.md).

[Oboe library ©The Android Open Source Project](https://github.com/google/oboe) χρησιμοποιείται για την αναπαραγωγή του ήχου με χαμηλή καθυστέρηση και διατίθεται για χρήση υπό την [άδεια Apache 2.0](https://github.com/google/oboe/blob/main/LICENSE).

[Η αρχική εφαρμογή Soundscape ©Microsoft Corporation](https://github.com/microsoft/soundscape) παρείχε τους ήχους του ηχητικού σήματος και πολλές από τις μεταφράσεις, και διατίθεται για χρήση υπό την [άδεια MIT](https://github.com/microsoft/soundscape/blob/main/LICENSE.txt).

Εθελοντές του [Soundscape Community ©Soundscape Community contributors](https://github.com/soundscape-community/soundscape) βελτίωσαν αρκετές από τις μεταφράσεις, οι οποίες διατίθενται για χρήση υπό την [άδεια MIT](https://github.com/soundscape-community/soundscape/blob/main/LICENSE.txt).

Όλα τα ονόματα προϊόντων, εταιρειών και λογότυπα τρίτων είναι εμπορικά σήματα ή καταχωρημένα εμπορικά σήματα και παραμένουν ιδιοκτησία των αντίστοιχων κατόχων τους.
