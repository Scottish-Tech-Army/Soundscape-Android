# আমার সামনে

*আমার সামনে* আপনার সামনের সর্বোচ্চ পাঁচটি স্থান কলআউট করে। প্রতিটি আপনি তার নিজের দিক থেকে, দূরত্বসহ শোনেন। অচেনা রাস্তায় সামনে কী আছে তা জানতে এটি ব্যবহার করুন।

আপনি এক জায়গায় দাঁড়িয়ে থাকলে, আগে ফোনের উপরের প্রান্তটি আপনি যেদিকে মুখ করে আছেন সেদিকে ধরুন। ফোন লক থাকলে, বা Soundscape স্ক্রিনে না থাকলে, ফোনটি সমতল করেও ধরুন।
