# GPS துல்லியம்

## GPS துல்லியம்

நீங்கள் எங்கே இருக்கிறீர்கள் என்பதை உங்கள் ஃபோன் எவ்வளவு துல்லியமாக அறிகிறதோ, அவ்வளவு துல்லியமாகவே Soundscape உங்கள் சுற்றுப்புறத்தை விவரிக்க முடியும். 10 மீட்டர் (30 அடி) அல்லது அதைவிடச் சிறந்த துல்லியம் நல்லது, 20 மீட்டர் (60 அடி) வரை பயன்படுத்தக்கூடியது, அதைவிட அதிகமாக இருந்தால் அறிவிப்புகள் தெருவின் தவறான பக்கத்தைக் குறிப்பிடலாம் அல்லது தாமதமாக வரலாம்.

கட்டடங்களுக்குள், உயரமான கட்டடங்களுக்கு இடையே, வெளியே சென்ற பிறகு முதல் ஒரு நிமிடம் அல்லது அதை ஒட்டிய நேரத்தில் துல்லியம் பொதுவாக மிக மோசமாக இருக்கும். திறந்த வெளியில் இருக்கும்போதும் கீழே உள்ள எண் மோசமாகவே இருந்தால், உங்கள் ஃபோனின் இருப்பிடச் சேவைகளை அணைத்துவிட்டு மீண்டும் இயக்கிப் பாருங்கள்.

தற்போதைய துல்லியம்: %1$s (%2$s)
