# Utilizarea Soundscape offline

## Utilizarea Soundscape offline

În mod normal, Soundscape descarcă datele hărții pe măsură ce te deplasezi. Fără conexiune la internet nu poate face asta. Pentru ca totul să funcționeze în continuare, descarcă o hartă offline înainte de călătorie.

## Descărcarea unei hărți offline

1. Deschide meniul și selectează *Hărți offline*.

2. Selectează o hartă din *Hărți offline din apropiere*.

3. Selectează *Descarcă harta offline*.

Hărțile pot fi mari, așa că folosește Wi-Fi dacă poți.

## Fără o hartă offline

Anunțurile pot funcționa în continuare în locurile vizitate recent, deoarece telefonul păstrează o vreme unele date ale hărții. Căutarea găsește doar marcajele tale. Totul revine la normal când telefonul este din nou online.
