# Création de marqueurs

Le moyen le plus rapide de créer un marqueur est l’écran *Marqueurs* : sélectionnez le bouton *Nouveau* dans le coin supérieur droit de l’écran, puis choisissez *Emplacement actuel* ou un lieu dans l’une des catégories des *Emplacements à proximité*. Vous pouvez aussi enregistrer n’importe quel lieu trouvé depuis l’écran d’accueil, avec la barre de recherche, le bouton *Emplacements à proximité* ou le bouton *Emplacement actuel*. Sélectionner un lieu vous mène à l’écran *Détails de l’emplacement*, où vous appuyez sur le bouton *Enregistrer en tant que marqueur*.

Vous avez maintenant la possibilité de personnaliser ce marqueur. Si vous le souhaitez, vous pouvez modifier le nom du marqueur et ajouter une annotation qui sera annoncée avec le marqueur pour fournir des informations supplémentaires. Une fois que vous avez terminé, sélectionnez le bouton *Terminé* pour enregistrer votre marqueur.
