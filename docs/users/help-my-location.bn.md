# আমার অবস্থান

*আমার অবস্থান* জানায় আপনি কোথায় আছেন। এটি বলে আপনি কোন দিকে মুখ করে আছেন বা চলছেন, তারপর আপনি যে রাস্তায় বা ঠিকানায় আছেন তা বলে। বাস থেকে নামার সময়, কোনো ভবন থেকে বেরোনোর সময় বা দিক হারিয়ে ফেললে এটি ব্যবহার করুন।

আপনি এক জায়গায় দাঁড়িয়ে থাকলে, আগে ফোনের উপরের প্রান্তটি আপনি যেদিকে মুখ করে আছেন সেদিকে ধরুন। ফোন লক থাকলে, বা Soundscape স্ক্রিনে না থাকলে, ফোনটি সমতল করেও ধরুন।
