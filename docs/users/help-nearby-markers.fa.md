# نشانه‌های نزدیک

*نشانه‌های نزدیک* حداکثر چهار نشانه از نشانه‌های شما را اعلام می‌کند، یعنی نزدیک‌ترین‌ها را. هر کدام را از جهت خودش و همراه با فاصله‌اش می‌شنوید. از آن استفاده کنید تا با کمک مکان‌هایی که می‌شناسید موقعیت خود را پیدا کنید. نشانه‌هایی که بیش از حدود 2 کیلومتر فاصله دارند کنار گذاشته می‌شوند.

اگر ایستاده‌اید، ابتدا بالای گوشی را به سمتی بگیرید که رو به آن هستید. اگر گوشی قفل است، یا ساند‌اسکیپ روی صفحه نیست، گوشی را افقی هم نگه دارید.
