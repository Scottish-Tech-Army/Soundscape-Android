# 前方

*前方* は、前方にある場所を最大 5 つコールアウトします。それぞれが、その方向から距離とともに聞こえます。知らない道で、この先に何があるかを知るために使ってください。

立ち止まっているときは、まずスマートフォンの上端を自分が向いている方向に向けてください。スマートフォンがロックされている場合や、Soundscape が画面に表示されていない場合は、スマートフォンを水平にも持ってください。
