# Personalización de marcadores

Si deseas cambiar el nombre de un marcador que has creado anteriormente, o agregarle una anotación, selecciona el marcador en la pantalla *Marcadores* y, luego, *Editar marcador*. Puedes usarlo para asignar a los marcadores sobrenombres útiles o descriptivos, así como para proporcionarles una descripción más larga con el campo de anotación.

En esta pantalla *Editar marcador*, también puedes eliminar un marcador si ya no lo necesitas.
