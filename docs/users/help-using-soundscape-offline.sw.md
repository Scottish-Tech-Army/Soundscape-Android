# Kutumia Soundscape Nje ya Mtandao

## Kutumia Soundscape Nje ya Mtandao

Kwa kawaida Soundscape inapakua data ya ramani kadiri unavyosogea. Bila muunganisho wa intaneti haiwezi kufanya hivyo. Ili kila kitu kiendelee kufanya kazi, pakua ramani ya nje ya mtandao kabla ya kusafiri.

## Kupakua ramani ya nje ya mtandao

1. Fungua menyu na uchague *Ramani za Nje ya Mtandao*.

2. Chagua ramani kutoka *Ramani za nje ya mtandao zilizo karibu*.

3. Chagua *Pakua ramani ya nje ya mtandao*.

Ramani zinaweza kuwa kubwa, kwa hiyo tumia Wi-Fi ukiweza.

## Bila ramani ya nje ya mtandao

Matangazo yanaweza kuendelea kufanya kazi katika sehemu ulizotembelea hivi karibuni, kwa sababu simu yako huhifadhi baadhi ya data ya ramani kwa muda. Utafutaji unapata alama zako tu. Kila kitu kinarudi kawaida simu yako inaporudi mtandaoni.
