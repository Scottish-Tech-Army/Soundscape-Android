# ਮਾਰਕਰ ਬਣਾਉਣਾ

ਮਾਰਕਰ ਬਣਾਉਣ ਦਾ ਸਭ ਤੋਂ ਤੇਜ਼ ਤਰੀਕਾ *ਮਾਰਕਰ* ਸਕ੍ਰੀਨ ਹੈ: ਸਕ੍ਰੀਨ ਦੇ ਉੱਪਰ ਸੱਜੇ ਕੋਨੇ ਵਿੱਚ *ਨਵਾਂ* ਬਟਨ ਚੁਣੋ, ਫਿਰ *ਮੌਜੂਦਾ ਟਿਕਾਣਾ* ਜਾਂ *ਨੇੜਲੀਆਂ ਥਾਵਾਂ* ਦੀ ਕਿਸੇ ਸ਼੍ਰੇਣੀ ਵਿੱਚੋਂ ਕੋਈ ਥਾਂ ਚੁਣੋ। ਤੁਸੀਂ ਹੋਮ ਸਕ੍ਰੀਨ ਤੋਂ ਲੱਭੀ ਕੋਈ ਵੀ ਥਾਂ ਖੋਜ ਪੱਟੀ, *ਨੇੜਲੀਆਂ ਥਾਵਾਂ* ਬਟਨ ਜਾਂ *ਮੌਜੂਦਾ ਟਿਕਾਣਾ* ਬਟਨ ਨਾਲ ਵੀ ਸੇਵ ਕਰ ਸਕਦੇ ਹੋ। ਕੋਈ ਥਾਂ ਚੁਣਨ ਨਾਲ ਤੁਸੀਂ *ਟਿਕਾਣੇ ਦੇ ਵੇਰਵੇ* ਸਕ੍ਰੀਨ 'ਤੇ ਪਹੁੰਚ ਜਾਂਦੇ ਹੋ, ਜਿੱਥੇ ਤੁਸੀਂ *ਮਾਰਕਰ ਵਜੋਂ ਸੇਵ ਕਰੋ* ਬਟਨ ਚੁਣਦੇ ਹੋ।

ਹੁਣ ਤੁਸੀਂ ਇਸ ਮਾਰਕਰ ਨੂੰ ਆਪਣੇ ਮੁਤਾਬਕ ਬਣਾ ਸਕਦੇ ਹੋ। ਤੁਸੀਂ ਮਾਰਕਰ ਦਾ ਨਾਮ ਬਦਲ ਸਕਦੇ ਹੋ, ਅਤੇ ਇੱਕ ਨੋਟ ਵੀ ਜੋੜ ਸਕਦੇ ਹੋ ਜੋ ਕੁਝ ਵਾਧੂ ਜਾਣਕਾਰੀ ਦੇਣ ਲਈ ਮਾਰਕਰ ਦੇ ਨਾਲ ਬੋਲਿਆ ਜਾਵੇਗਾ। ਪੂਰਾ ਹੋਣ 'ਤੇ, ਆਪਣਾ ਮਾਰਕਰ ਸੇਵ ਕਰਨ ਲਈ *ਹੋ ਗਿਆ* ਬਟਨ ਚੁਣੋ।
