# ਮਾਰਕਰ ਬਣਾਉਣਾ

ਤੁਸੀਂ ਤਿੰਨ ਤਰੀਕਿਆਂ ਨਾਲ ਮਾਰਕਰ ਬਣਾ ਸਕਦੇ ਹੋ: ਖੋਜ ਪੱਟੀ ਨਾਲ ਉਹ ਥਾਂ ਖੋਜ ਕੇ ਜੋ ਤੁਸੀਂ ਸੇਵ ਕਰਨਾ ਚਾਹੁੰਦੇ ਹੋ, *ਨੇੜਲੀਆਂ ਥਾਵਾਂ* ਬਟਨ ਨਾਲ ਕੋਈ ਥਾਂ ਲੱਭ ਕੇ, ਜਾਂ *ਮੌਜੂਦਾ ਟਿਕਾਣਾ* ਬਟਨ ਵਰਤ ਕੇ; ਇਹ ਸਾਰੇ ਹੋਮ ਸਕ੍ਰੀਨ 'ਤੇ ਹਨ। ਜਦੋਂ ਤੁਹਾਨੂੰ ਆਪਣੀ ਚਾਹੀ ਥਾਂ ਮਿਲ ਜਾਵੇ, ਉਸਨੂੰ ਚੁਣਨ ਨਾਲ ਤੁਸੀਂ *ਟਿਕਾਣੇ ਦੇ ਵੇਰਵੇ* ਸਕ੍ਰੀਨ 'ਤੇ ਪਹੁੰਚ ਜਾਓਗੇ। ਇਸ ਸਕ੍ਰੀਨ 'ਤੇ *ਮਾਰਕਰ ਵਜੋਂ ਸੇਵ ਕਰੋ* ਬਟਨ ਚੁਣੋ।

ਹੁਣ ਤੁਸੀਂ ਇਸ ਮਾਰਕਰ ਨੂੰ ਆਪਣੇ ਮੁਤਾਬਕ ਬਣਾ ਸਕਦੇ ਹੋ। ਤੁਸੀਂ ਮਾਰਕਰ ਦਾ ਨਾਮ ਬਦਲ ਸਕਦੇ ਹੋ, ਅਤੇ ਇੱਕ ਨੋਟ ਵੀ ਜੋੜ ਸਕਦੇ ਹੋ ਜੋ ਕੁਝ ਵਾਧੂ ਜਾਣਕਾਰੀ ਦੇਣ ਲਈ ਮਾਰਕਰ ਦੇ ਨਾਲ ਬੋਲਿਆ ਜਾਵੇਗਾ। ਪੂਰਾ ਹੋਣ 'ਤੇ, ਆਪਣਾ ਮਾਰਕਰ ਸੇਵ ਕਰਨ ਲਈ *ਹੋ ਗਿਆ* ਬਟਨ ਚੁਣੋ।
