# 마커 만들기

마커를 가장 빠르게 만드는 방법은 *마커* 화면을 이용하는 것입니다. 화면 오른쪽 상단의 *새로 만들기* 버튼을 선택한 다음 *현재 위치* 또는 *주변 장소* 카테고리 중 하나에 있는 장소를 선택하세요. 홈 화면에서 찾은 장소도 검색창, *주변 장소* 버튼 또는 *현재 위치* 버튼을 사용하여 저장할 수 있습니다. 장소를 선택하면 *위치 세부 정보* 화면으로 이동하며, 여기서 *마커로 저장* 버튼을 선택하면 됩니다.

이제 이 마커를 원하는 대로 설정할 수 있습니다. 마커의 이름을 변경할 수 있으며, 마커와 함께 안내될 추가 정보를 제공하는 메모를 추가할 수도 있습니다. 설정을 마쳤으면 *완료* 버튼을 선택하여 마커를 저장하세요.
