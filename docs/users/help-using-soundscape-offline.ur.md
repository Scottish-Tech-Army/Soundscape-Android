# Soundscape کا آف لائن استعمال

## Soundscape کا آف لائن استعمال

Soundscape عام طور پر آپ کے حرکت کرنے کے ساتھ ساتھ نقشے کا ڈیٹا ڈاؤن لوڈ کرتا ہے۔ انٹرنیٹ کنکشن کے بغیر یہ ایسا نہیں کر سکتا۔ سب کچھ چلتا رکھنے کے لیے سفر سے پہلے ایک آف لائن نقشہ ڈاؤن لوڈ کریں۔

## آف لائن نقشہ ڈاؤن لوڈ کرنا

1. مینو کھولیں اور *آف لائن نقشے* منتخب کریں۔

2. *قریبی آف لائن نقشے* میں سے ایک نقشہ منتخب کریں۔

3. *آف لائن نقشہ ڈاؤن لوڈ کریں* منتخب کریں۔

نقشے بڑے ہو سکتے ہیں، اس لیے ممکن ہو تو Wi-Fi استعمال کریں۔

## آف لائن نقشے کے بغیر

کالآؤٹس ان جگہوں پر اب بھی کام کر سکتے ہیں جہاں آپ حال ہی میں گئے تھے، کیونکہ آپ کا فون نقشے کا کچھ ڈیٹا کچھ دیر تک محفوظ رکھتا ہے۔ تلاش میں صرف آپ کے مارکرز ملتے ہیں۔ جب فون دوبارہ آن لائن ہوتا ہے تو سب کچھ معمول پر آ جاتا ہے۔
