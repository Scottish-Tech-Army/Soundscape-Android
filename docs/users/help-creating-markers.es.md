# Creación de marcadores

Puedes crear marcadores de tres maneras: buscando el lugar que deseas guardar usando la barra de búsqueda, encontrando un lugar con el botón *Lugares cercanos* o usando el botón *Ubicación actual*, todo ello en la pantalla principal de Soundscape. Una vez que hayas encontrado el lugar que deseas, al seleccionarlo, irás a la pantalla *Detalles de la ubicación*. En esta pantalla, selecciona el botón *Guardar como marcador*.

Tendrás la opción de personalizar este marcador. Si lo deseas, puedes cambiar el nombre del marcador y también agregar una anotación que se oirá con el marcador para proporcionar información adicional. Una vez que hayas acabado, selecciona el botón *"Listo"* para guardar el marcador.
