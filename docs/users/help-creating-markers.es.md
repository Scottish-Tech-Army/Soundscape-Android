# Creación de marcadores

La forma más rápida de crear un marcador es desde la pantalla *Marcadores*: selecciona el botón *Nuevo* de la esquina superior derecha de la pantalla y, a continuación, elige *Ubicación actual* o un lugar de una de las categorías de *Lugares cercanos*. También puedes guardar cualquier lugar que encuentres desde la pantalla principal, con la barra de búsqueda, el botón *Lugares cercanos* o el botón *Ubicación actual*. Al seleccionar un lugar, irás a la pantalla *Detalles de la ubicación*, donde debes seleccionar el botón *Guardar como marcador*.

Tendrás la opción de personalizar este marcador. Si lo deseas, puedes cambiar el nombre del marcador y también agregar una anotación que se oirá con el marcador para proporcionar información adicional. Una vez que hayas acabado, selecciona el botón *«Listo»* para guardar el marcador.
