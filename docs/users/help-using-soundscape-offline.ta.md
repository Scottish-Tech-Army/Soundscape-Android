# Soundscape-ஐ ஆஃப்லைனில் பயன்படுத்துதல்

## Soundscape-ஐ ஆஃப்லைனில் பயன்படுத்துதல்

Soundscape பொதுவாக நீங்கள் நகரும்போதே வரைபடத் தரவைப் பதிவிறக்குகிறது. இணைய இணைப்பு இல்லாமல் அதனால் அதைச் செய்ய முடியாது. எல்லாம் தொடர்ந்து இயங்க, பயணத்துக்கு முன் ஓர் ஆஃப்லைன் வரைபடத்தைப் பதிவிறக்கவும்.

## ஆஃப்லைன் வரைபடத்தைப் பதிவிறக்குதல்

1. மெனுவைத் திறந்து *ஆஃப்லைன் வரைபடங்கள்* என்பதைத் தேர்ந்தெடுக்கவும்.

2. *அருகிலுள்ள ஆஃப்லைன் வரைபடங்கள்* என்பதிலிருந்து ஒரு வரைபடத்தைத் தேர்ந்தெடுக்கவும்.

3. *ஆஃப்லைன் வரைபடத்தைப் பதிவிறக்கு* என்பதைத் தேர்ந்தெடுக்கவும்.

வரைபடங்கள் பெரியதாக இருக்கலாம், எனவே முடிந்தால் Wi-Fi பயன்படுத்தவும்.

## ஆஃப்லைன் வரைபடம் இல்லாமல்

நீங்கள் சமீபத்தில் சென்ற இடங்களில் அறிவிப்புகள் இன்னும் செயல்படலாம், ஏனெனில் தொலைபேசி சில வரைபடத் தரவைச் சிறிது காலம் வைத்திருக்கும். தேடலில் உங்கள் குறிப்பான்கள் மட்டுமே கிடைக்கும். தொலைபேசி மீண்டும் ஆன்லைனுக்கு வந்ததும் எல்லாம் இயல்புநிலைக்குத் திரும்பும்.
