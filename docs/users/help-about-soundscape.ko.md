# Soundscape 정보

Soundscape는 혁신적인 오디오 기반 기술을 사용하여 사람들이 주변 환경을 더 풍부하게 인식할 수 있도록 돕습니다. 이를 통해 사람들은 더 자신감을 갖고 스스로 이동할 수 있게 됩니다.

Soundscape는 이 훌륭한 타사 라이브러리와 데이터를 기반으로 합니다. 링크를 클릭하면 각 라이선스를 확인할 수 있습니다:

[©OpenStreetMap contributors](https://www.openstreetmap.org/copyright)가 Soundscape에서 사용되는 모든 지도 및 오디오용 지리 데이터를 제공합니다.

[©OpenMapTiles](https://github.com/openmaptiles/openmaptiles/blob/master/LICENSE.md)는 저희가 사용하는 지도 타일을 생성하는 데 사용됩니다.

[Steam Audio library ©Valve Corporation](https://github.com/ValveSoftware/steam-audio)는 3D 오디오를 생성하는 데 사용되며, [Apache 2.0 license](https://github.com/ValveSoftware/steam-audio/blob/master/LICENSE.md)에 따라 사용할 수 있습니다.

[Oboe library ©The Android Open Source Project](https://github.com/google/oboe)는 낮은 지연 시간으로 오디오를 재생하는 데 사용되며, [Apache 2.0 license](https://github.com/google/oboe/blob/main/LICENSE)에 따라 사용할 수 있습니다.

모든 타사 제품명, 회사명 및 로고는 각 소유권자의 상표 또는 등록 상표이며, 해당 소유권자의 자산입니다.
