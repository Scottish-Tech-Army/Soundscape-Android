# Voces

Soundscape puede usar cualquier voz instalada en tu teléfono. Para añadir voces, abre los ajustes de tu teléfono y busca *Salida de texto a voz*. Para elegir una voz en Soundscape, abre el menú y selecciona *Ajustes*, después *Audio* y después *Voces*.
