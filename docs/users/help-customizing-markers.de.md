# Anpassen von Markierungen

Wenn Sie eine zuvor erstellte Markierung umbenennen oder ihr eine Anmerkung hinzufügen möchten, wählen Sie die Markierung auf dem Bildschirm *„Markierungen“* aus und tippen Sie dann auf die Schaltfläche *„Markierung bearbeiten“*. Damit können Sie Markierungen aussagekräftige oder nützliche Spitznamen geben und im Feld für Anmerkungen eine längere Beschreibung einfügen.

Auf dem Bildschirm *„Markierung bearbeiten“* können Sie eine Markierung auch löschen, wenn Sie sie nicht mehr benötigen.
