# การสร้างหมุด

วิธีที่เร็วที่สุดในการสร้างหมุดคือจากหน้าจอ *หมุด* เลือกปุ่ม *ใหม่* ที่มุมขวาบนของหน้าจอ แล้วเลือก *ตำแหน่งปัจจุบัน* หรือสถานที่ในหมวดหมู่หนึ่งของ *สถานที่ใกล้เคียง* คุณยังบันทึกสถานที่ใดก็ได้ที่พบจากหน้าจอหลัก โดยใช้แถบค้นหา ปุ่ม *สถานที่ใกล้เคียง* หรือปุ่ม *ตำแหน่งปัจจุบัน* การเลือกสถานที่จะพาคุณไปยังหน้าจอ *รายละเอียดตำแหน่ง* ซึ่งคุณเลือกปุ่ม *บันทึกเป็นหมุด* ได้

ตอนนี้คุณจะมีตัวเลือกในการปรับแต่งหมุดนี้ คุณสามารถเปลี่ยนชื่อของหมุด และเพิ่มคำอธิบายประกอบที่จะถูกแจ้งเตือนพร้อมกับหมุดเพื่อให้ข้อมูลเพิ่มเติม เมื่อเสร็จแล้ว ให้เลือกปุ่ม *เสร็จสิ้น* เพื่อบันทึกหมุดของคุณ
