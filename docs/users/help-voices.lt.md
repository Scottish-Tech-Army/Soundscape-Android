# Balsai

Soundscape gali naudoti bet kurį telefone įdiegtą balsą. Norėdami pridėti balsų, atidarykite telefono nustatymus ir suraskite *Teksto į kalbą išvestis*. Norėdami pasirinkti balsą programoje Soundscape, atidarykite meniu ir pasirinkite *Nustatymai*, tada *Garsas*, tada *Balsai*.
