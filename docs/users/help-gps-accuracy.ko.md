# GPS 정확도

## GPS 정확도

Soundscape는 휴대폰이 현재 위치를 아는 만큼만 주변을 정확하게 설명할 수 있습니다. 정확도가 10미터 이내이면 좋습니다. 20미터까지는 괜찮습니다. 그보다 나쁘면 안내가 길의 반대편을 말하거나 늦게 나올 수 있습니다.

정확도는 보통 실내, 높은 건물 사이, 그리고 밖으로 나온 뒤 처음 1분 동안 가장 나쁩니다. 탁 트인 야외에 있는데도 아래 수치가 계속 나쁘면 휴대폰의 위치 서비스를 껐다가 다시 켜세요.
