# GPS 정확도

## GPS 정확도

Soundscape는 휴대폰이 사용자의 위치를 아는 만큼만 정확하게 주변 환경을 설명할 수 있습니다. 정확도가 10미터(30피트) 이내이면 좋음, 20미터(60피트)까지는 사용 가능한 수준이며, 그보다 크면 안내가 길의 반대편을 알려 주거나 늦게 나올 수 있습니다.

정확도는 보통 실내, 높은 건물 사이, 그리고 밖으로 나간 후 처음 1분 정도 동안 가장 나쁩니다. 탁 트인 야외에 있는데도 아래 수치가 계속 나쁘면 휴대폰의 위치 서비스를 껐다가 다시 켜 보세요.
