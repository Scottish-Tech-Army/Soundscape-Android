# GPS の精度

## GPS の精度

Soundscape が周囲の状況を説明できる正確さは、スマートフォンがあなたの位置をどれだけ正確に把握しているかで決まります。精度が 10 メートル (30 フィート) 以内なら良好、20 メートル (60 フィート) までなら使用可能です。それより大きい場合は、コールアウトが道路の反対側を案内したり、遅れて届いたりすることがあります。

精度は通常、屋内や高い建物の間、そして屋外に出てから最初の 1 分ほどの間に最も悪くなります。屋外の開けた場所にいるのに下の数値が悪いままの場合は、スマートフォンの位置情報サービスをオフにしてから、もう一度オンにしてみてください。

現在の精度: %1$s (%2$s)
