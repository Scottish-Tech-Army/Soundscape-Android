# ਆਵਾਜ਼ਾਂ

Soundscape ਤੁਹਾਡੇ Android ਫ਼ੋਨ ਦੀਆਂ ਟੈਕਸਟ-ਟੂ-ਸਪੀਚ ਆਊਟਪੁੱਟ ਸੈਟਿੰਗਾਂ ਵਿੱਚ ਡਾਊਨਲੋਡ ਕੀਤੀ ਕੋਈ ਵੀ ਆਵਾਜ਼ ਵਰਤ ਸਕਦਾ ਹੈ। Soundscape ਐਪ ਵਿੱਚ Android ਦੀ ਮੂਲ ਆਵਾਜ਼ ਤੋਂ ਇਲਾਵਾ ਕੋਈ ਹੋਰ ਆਵਾਜ਼ ਚੁਣਨ ਲਈ, ਮੁੱਖ ਮੀਨੂ ਤੋਂ *ਸੈਟਿੰਗਾਂ* 'ਤੇ ਜਾਓ, *ਆਡੀਓ* ਹਿੱਸਾ ਖੋਲ੍ਹੋ, ਅਤੇ ਫਿਰ *ਆਵਾਜ਼ਾਂ* ਚੁਣੋ।
