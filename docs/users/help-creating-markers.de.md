# Erstellen von Markierungen

Am schnellsten erstellen Sie eine Markierung auf dem Bildschirm *„Markierungen“*: Wählen Sie oben rechts auf dem Bildschirm die Schaltfläche *„Neu“* und dann *„Aktueller Standort“* oder einen Ort aus einer der Kategorien von *„Orte in der Nähe“*. Sie können auch jeden Ort speichern, den Sie über den Startbildschirm finden, mit der Suchleiste, der Schaltfläche *„Orte in der Nähe“* oder der Schaltfläche *„Aktueller Standort“*. Wenn Sie einen Ort auswählen, gelangen Sie zum Bildschirm *„Standortdetails“*, wo Sie die Schaltfläche *„Als Markierung speichern“* wählen.

Sie haben nun die Möglichkeit, diese Markierung anzupassen. Sie können den Namen der Markierung ändern und zudem eine Notiz hinzufügen, die zusammen mit der Markierung angesagt wird, um zusätzliche Informationen zu liefern. Wenn Sie fertig sind, wählen Sie die Schaltfläche *„Fertig“*, um Ihre Markierung zu speichern.
