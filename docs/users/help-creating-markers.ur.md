# مارکرز بنانا

مارکر بنانے کا سب سے تیز طریقہ *مارکرز* اسکرین ہے: اسکرین کے اوپری بائیں کونے میں موجود *نیا* بٹن منتخب کریں، پھر *موجودہ مقام* یا *قریبی مقامات* کے کسی زمرے سے کوئی جگہ منتخب کریں۔ آپ ہوم اسکرین سے ملنے والی کوئی بھی جگہ سرچ بار، *قریبی مقامات* بٹن یا *موجودہ مقام* بٹن کے ذریعے بھی محفوظ کر سکتے ہیں۔ کوئی جگہ منتخب کرنے سے آپ *مقام کی تفصیلات* اسکرین پر پہنچ جاتے ہیں، جہاں آپ *بطور مارکر محفوظ کریں* بٹن منتخب کرتے ہیں۔

اب آپ کے پاس اس مارکر کو حسبِ ضرورت بنانے کا اختیار ہوگا۔ آپ مارکر کا نام تبدیل کر سکتے ہیں، اور اضافی معلومات فراہم کرنے کے لیے ایک نوٹ بھی شامل کر سکتے ہیں جو مارکر کے ساتھ پکارا جائے گا۔ مکمل ہونے پر، اپنے مارکر کو محفوظ کرنے کے لیے *ہو گیا* بٹن منتخب کریں۔
