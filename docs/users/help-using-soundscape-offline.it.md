# Usare Soundscape offline

## Usare Soundscape offline

Di norma Soundscape scarica i dati delle mappe mentre ti sposti. Senza connessione a Internet non può farlo. Perché tutto continui a funzionare, scarica una mappa offline prima di partire.

## Scaricare una mappa offline

1. Apri il menu e seleziona *Mappe offline*.

2. Seleziona una mappa in *Mappe offline nelle vicinanze*.

3. Seleziona *Scarica la mappa offline*.

Le mappe possono essere grandi, quindi usa il Wi-Fi se puoi.

## Senza una mappa offline

Le notifiche possono funzionare ancora nei luoghi che hai visitato di recente, perché il telefono conserva alcuni dati delle mappe per un po'. La ricerca trova solo i tuoi indicatori. Tutto torna normale quando il telefono è di nuovo online.
