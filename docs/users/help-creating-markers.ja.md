# マーカーの作成

マーカーをいちばん早く作成できるのは *「マーカー」* 画面です。画面右上の *「新規」* ボタンを選択し、*「現在地」* または *「近くの場所」* のいずれかのカテゴリにある場所を選んでください。ホーム画面で見つけた場所も、検索バー、*「近くの場所」* ボタン、*「現在地」* ボタンを使って保存できます。場所を選択すると *「場所の詳細」* 画面に移動するので、そこで *「マーカーを保存」* ボタンを選択してください。

ここでこのマーカーをカスタマイズできます。名前を変更したり、マーカーと一緒に読み上げる注記を追加して補足情報を付けることができます。完了したら *「完了」* を選択してマーカーを保存してください。
