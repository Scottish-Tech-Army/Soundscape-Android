# 创建标记点

创建标记点最快的方法是使用*标记点*屏幕：选择屏幕右上角的*新建*按钮，然后选择*当前位置*或*附近地点*某个类别中的地点。您也可以通过搜索栏、*附近地点*按钮或*当前位置*按钮，保存在主屏幕上找到的任何地点。选择地点后将进入*位置详情*屏幕，在该屏幕上选择*保存为标记点*按钮。

现在您可以自定义此标记点。您可以更改标记点的名称，还可以添加注释，注释会与标记点一起播报以提供额外信息。完成后，点击*“完成”*按钮保存您的标记点。
