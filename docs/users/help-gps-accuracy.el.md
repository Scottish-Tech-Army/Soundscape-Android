# Ακρίβεια GPS

## Ακρίβεια GPS

Το Soundscape μπορεί να περιγράψει το περιβάλλον σας μόνο με την ακρίβεια με την οποία το τηλέφωνό σας γνωρίζει πού βρίσκεστε. Ακρίβεια 10 μέτρων (30 ποδιών) ή καλύτερη είναι καλή, έως 20 μέτρα (60 πόδια) είναι αποδεκτή, και οτιδήποτε μεγαλύτερο σημαίνει ότι οι επεξηγήσεις μπορεί να αναφέρουν τη λάθος πλευρά του δρόμου ή να έρχονται με καθυστέρηση.

Η ακρίβεια είναι συνήθως χειρότερη σε εσωτερικούς χώρους, ανάμεσα σε ψηλά κτίρια και περίπου στο πρώτο λεπτό αφού βγείτε έξω. Αν η τιμή παρακάτω παραμένει κακή ενώ βρίσκεστε έξω σε ανοιχτό χώρο, δοκιμάστε να απενεργοποιήσετε και να ενεργοποιήσετε ξανά τις υπηρεσίες τοποθεσίας του τηλεφώνου σας.

Τρέχουσα ακρίβεια: %1$s (%2$s)
