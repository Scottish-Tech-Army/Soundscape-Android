# ヒント

近くのバス停を探すには、*近くの場所* を選択して *公共交通機関* を選びます。

同じバスによく乗る場合は、利用するバス停をマーカーとして保存してください。降りるバス停にビーコンを設定すると、乗車中に Soundscape がそこまでの距離を知らせます。

ビーコンをミュートしても、場所までの距離は聞くことができます。移動している間、Soundscape はときどき距離を読み上げます。

出かける前に場所を調べるには、その場所の *場所の詳細* を開いて *位置のシミュレーション* を選択します。すると Soundscape は、あなたがそこにいるかのように動作します。

曲がり角ごとの道案内が必要なときは、場所の *場所の詳細* を開いて *地図アプリで開く* を選択します。ほかのアプリが道案内をしている間も、Soundscape は動作し続けます。
