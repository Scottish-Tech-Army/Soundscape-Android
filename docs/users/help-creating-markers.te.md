# మార్కర్‌లను సృష్టించడం

మార్కర్‌ను సృష్టించడానికి వేగవంతమైన మార్గం *మార్కర్‌లు* స్క్రీన్: స్క్రీన్ ఎగువ-కుడి మూలలో ఉన్న *కొత్తది* బటన్‌ను ఎంచుకుని, తర్వాత *ప్రస్తుత స్థానం* లేదా *సమీప స్థలాలు* వర్గాలలో ఒకదానిలోని ప్రదేశాన్ని ఎంచుకోండి. హోమ్ స్క్రీన్ నుండి మీరు కనుగొన్న ఏ ప్రదేశాన్నైనా శోధన పట్టీ, *సమీప స్థలాలు* బటన్ లేదా *ప్రస్తుత స్థానం* బటన్ ఉపయోగించి కూడా సేవ్ చేయవచ్చు. ఒక ప్రదేశాన్ని ఎంచుకుంటే మీరు *స్థాన వివరాలు* స్క్రీన్‌కు వెళ్తారు, అక్కడ *మార్కర్‌గా సేవ్ చేయి* బటన్‌ను ఎంచుకోండి.

ఇప్పుడు మీకు ఈ మార్కర్‌ను అనుకూలీకరించే ఆప్షన్ ఉంటుంది. మీరు మార్కర్ పేరును మార్చవచ్చు, అలాగే అదనపు సమాచారాన్ని అందించడానికి మార్కర్‌తో పాటు కాలౌట్ చేయబడే ఒక అనొటేషన్‌ను కూడా జోడించవచ్చు. మీరు పూర్తి చేసిన తర్వాత, మీ మార్కర్‌ను సేవ్ చేయడానికి *పూర్తయింది* బటన్‌ను ఎంచుకోండి.
