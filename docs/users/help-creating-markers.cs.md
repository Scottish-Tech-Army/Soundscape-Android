# Vytváření značek

Nejrychleji vytvoříte značku na obrazovce *Značky*: vyberte tlačítko *Nová* v pravém horním rohu obrazovky a poté zvolte *Aktuální poloha* nebo místo v některé z kategorií *Místa v okolí*. Uložit můžete také jakékoli místo, které najdete z domovské obrazovky pomocí vyhledávacího pole, tlačítka *Místa v okolí* nebo tlačítka *Aktuální poloha*. Výběrem místa se dostanete na obrazovku *Podrobnosti o místě*, kde vyberete tlačítko *Uložit jako značku*.

Nyní máte možnost tuto značku upravit. Můžete změnit název značky a také přidat poznámku, která bude oznámena společně se značkou a poskytne dodatečné informace. Jakmile budete hotovi, výběrem tlačítka *Hotovo* značku uložíte.
