# குறிப்பான்களை உருவாக்குதல்

குறிப்பானை உருவாக்க விரைவான வழி *குறிப்பான்கள்* திரை: திரையின் மேல்-வலது மூலையில் உள்ள *புதியது* பொத்தானைத் தேர்ந்தெடுத்து, பின்னர் *தற்போதைய இருப்பிடம்* அல்லது *அருகிலுள்ள இடங்கள்* வகைகளில் ஒன்றில் உள்ள ஓர் இடத்தைத் தேர்ந்தெடுக்கவும். முகப்புத் திரையிலிருந்து நீங்கள் கண்டறியும் எந்த இடத்தையும் தேடல் பட்டி, *அருகிலுள்ள இடங்கள்* பொத்தான் அல்லது *தற்போதைய இருப்பிடம்* பொத்தானைப் பயன்படுத்தியும் சேமிக்கலாம். ஓர் இடத்தைத் தேர்ந்தெடுத்தால் *இருப்பிட விவரங்கள்* திரைக்குச் செல்வீர்கள், அங்கு *குறிப்பானாகச் சேமி* பொத்தானைத் தேர்ந்தெடுக்கவும்.

இப்போது இந்தக் குறிப்பானைத் தனிப்பயனாக்க உங்களுக்கு விருப்பம் இருக்கும். குறிப்பானின் பெயரை மாற்றலாம், மேலும் கூடுதல் தகவலை வழங்க குறிப்பானுடன் அறிவிக்கப்படும் ஒரு குறிப்பையும் சேர்க்கலாம். முடிந்ததும், உங்கள் குறிப்பானைச் சேமிக்க *முடிந்தது* பொத்தானைத் தேர்ந்தெடுக்கவும்.
