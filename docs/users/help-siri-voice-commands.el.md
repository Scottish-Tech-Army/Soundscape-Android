# Φωνητικές εντολές Siri

Στο iPhone, μπορείτε να ζητήσετε από τη Siri να κάνει πράγματα στο Soundscape χωρίς να αγγίξετε το τηλέφωνό σας. Για παράδειγμα, να ακούσετε μια επεξήγηση, να ξεκινήσετε μια διαδρομή ή να ορίσετε ηχητικό σήμα σε έναν δείκτη.

Το Soundscape απαντά με τη δική του φωνή, με τις συνηθισμένες επεξηγήσεις και τους ήχους του ηχητικού σήματος. Έτσι συνεχίζετε να ακούτε κάθε ήχο από την κατεύθυνση του μέρους.

Χρησιμοποιήστε φωνητικές εντολές όταν το τηλέφωνο είναι στην τσέπη σας ή έχετε τα χέρια σας γεμάτα. Λειτουργούν όταν το Soundscape είναι στο παρασκήνιο και όταν το τηλέφωνο είναι κλειδωμένο. Όταν ζητάτε μια επεξήγηση, η εφαρμογή δεν ανοίγει.

Η Siri είναι αυτή που ακούει, όχι το Soundscape. Έτσι το Soundscape δεν χρησιμοποιεί ποτέ το μικρόφωνό σας, και τα ακουστικά Bluetooth διατηρούν την υψηλή ποιότητα ήχου τους.

## Πώς να ζητήσετε

Κάθε εντολή έχει την ίδια μορφή: *«Soundscape»*, μετά μια ομάδα και μετά η επιλογή σας. Για παράδειγμα, *«Soundscape surroundings around me»*.

Μπορείτε επίσης να σταματήσετε μετά την ομάδα, και η Siri ρωτά ποια επιλογή θέλετε. Έτσι κάθε ομάδα λειτουργεί σαν προφορικό μενού. Υπάρχουν μόνο επτά ομάδες να θυμάστε.

## Τι μπορείτε να ζητήσετε

*«Soundscape surroundings»* — μετά *Η τοποθεσία μου*, *Γύρω μου*, *Μπροστά μου*, *Κοντινοί δείκτες*, *Επεξήγηση ηχητικού σήματος* ή *Πληροφορίες ηχητικού σήματος*.

*«Soundscape route»* — μετά *Επόμενο σημείο πορείας*, *Προηγούμενο σημείο πορείας*, *Σίγαση ηχητικού σήματος* ή *Διακοπή*.

*«Soundscape start route»* — μετά το όνομα μιας από τις διαδρομές σας.

*«Soundscape beacon»* — μετά το όνομα ενός από τους δείκτες σας.

*«Soundscape stop beacon»*.

*«Soundscape detail»* — μετά *Σιωπηλό*, *Βασικό*, *Απλοποιημένο* ή *Λεπτομερές*. Το *Σιωπηλό* απενεργοποιεί τις αυτόματες επεξηγήσεις.

*«Soundscape list»* — μετά *Διαδρομές*, *Δείκτες* ή *Εντολές*. Το *Εντολές* σας διαβάζει αυτή τη λίστα.

## Καλό είναι να γνωρίζετε

Οι εντολές εμφανίζονται επίσης στην εφαρμογή Συντομεύσεις και στην εφαρμογή Ρυθμίσεις του iOS, στην ενότητα *Siri*. Εκεί μπορείτε να δείτε ολόκληρη τη λίστα και να προσθέσετε τη δική σας διατύπωση για οποιαδήποτε εντολή.
