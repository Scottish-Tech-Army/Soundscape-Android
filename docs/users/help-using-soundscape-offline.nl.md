# Soundscape offline gebruiken

## Soundscape offline gebruiken

Normaal downloadt Soundscape kaartgegevens terwijl u onderweg bent. Zonder internetverbinding lukt dat niet. Download een offline kaart voordat u op reis gaat, dan blijft alles werken.

## Een offline kaart downloaden

1. Open het menu en selecteer *Offline kaarten*.

2. Selecteer een kaart bij *Offline kaarten in de buurt*.

3. Selecteer *Offline kaart downloaden*.

Kaarten kunnen groot zijn, dus gebruik wifi als dat kan.

## Zonder offline kaart

Aankondigingen werken mogelijk nog op plaatsen waar u pas bent geweest, omdat uw telefoon sommige kaartgegevens een tijdje bewaart. Zoeken vindt alleen uw markeringen. Alles werkt weer normaal zodra uw telefoon weer online is.
