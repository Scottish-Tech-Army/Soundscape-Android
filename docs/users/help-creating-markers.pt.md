# Criar Marcos

A forma mais rápida de criar um marco é a partir do ecrã *Marcos*: selecione o botão *Novo* no canto superior direito do ecrã e, em seguida, escolha *Localização Atual* ou um local numa das categorias de *Locais nas Proximidades*. Também pode guardar qualquer local que encontre a partir do ecrã principal, com a barra de pesquisa, o botão *Locais nas Proximidades* ou o botão *Localização Atual*. Ao selecionar um local, acede ao ecrã *Detalhes da Localização*, onde seleciona o botão *Guardar como Marco*.

Agora terá a opção de personalizar este marco. Pode alterar o nome do marco e também adicionar uma anotação que será anunciada juntamente com o marco para fornecer informação adicional. Quando terminar, selecione o botão *«OK»* para guardar o seu marco.
