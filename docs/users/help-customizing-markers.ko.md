# 마커 사용자 지정

이전에 만든 마커의 이름을 변경하거나 메모를 추가하려면, *\"마커 및 경로\"* 페이지의 *\"마커\"* 탭에서 해당 마커를 선택한 다음 *\"마커 편집\"* 버튼을 선택하면 됩니다. 이를 통해 마커에 설명적이거나 유용한 별칭을 붙이고, 메모 필드를 사용하여 더 자세한 설명을 추가할 수 있습니다.

이 *편집* 화면에서 더 이상 필요하지 않은 마커를 삭제할 수도 있습니다.
