# GPS 精度

## GPS 精度

Soundscape 描述您周围环境的准确程度，取决于手机对您所在位置的掌握程度。精度在 10 米（30 英尺）以内为良好，20 米（60 英尺）以内尚可使用，超过这个范围，播报可能会说错在街道的哪一侧，或者播报得太晚。

在室内、高楼之间以及刚到户外后的大约一分钟内，精度通常最差。如果您在户外空旷处时下方的数值仍然很差，请尝试关闭手机的定位服务后再重新打开。

当前精度：%1$s（%2$s）
