# GPS 精度

## GPS 精度

手机对您所在位置了解得有多准，Soundscape 对周围环境的描述就只能有多准。精度在 10 米以内为良好。20 米以内尚可。超过这个范围，提示可能会说错街道的哪一侧，或者来得太晚。

在室内、高楼之间，以及刚到室外的第一分钟里，精度通常最差。如果您在室外开阔处时下面的数值仍然很差，请关闭手机的定位服务，然后重新打开。

当前精度：%1$s（%2$s）
