# Membuat Penanda

Anda dapat membuat penanda dengan tiga cara: mencari tempat yang ingin Anda simpan menggunakan bilah pencarian, menemukan suatu tempat menggunakan tombol *Tempat di Sekitar*, atau menggunakan tombol *Lokasi Saat Ini*, yang semuanya dapat ditemukan di layar utama. Setelah Anda menemukan tempat yang diinginkan, memilihnya akan membawa Anda ke layar *Detail Lokasi*. Di layar ini, pilih tombol *Simpan sebagai Penanda*.

Anda sekarang memiliki opsi untuk menyesuaikan penanda ini. Anda dapat mengubah nama penanda, dan juga menambahkan anotasi yang akan disebutkan bersama penanda untuk memberikan informasi tambahan. Setelah selesai, pilih tombol *Selesai* untuk menyimpan Penanda Anda.
