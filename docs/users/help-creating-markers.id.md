# Membuat Penanda

Cara tercepat membuat penanda adalah dari layar *Penanda*: pilih tombol *Baru* di pojok kanan atas layar, lalu pilih *Lokasi Saat Ini* atau tempat dalam salah satu kategori *Tempat di Sekitar*. Anda juga dapat menyimpan tempat apa pun yang Anda temukan dari layar utama, menggunakan bilah pencarian, tombol *Tempat di Sekitar*, atau tombol *Lokasi Saat Ini*. Memilih suatu tempat akan membawa Anda ke layar *Detail Lokasi*, tempat Anda memilih tombol *Simpan sebagai Penanda*.

Anda sekarang memiliki opsi untuk menyesuaikan penanda ini. Anda dapat mengubah nama penanda, dan juga menambahkan anotasi yang akan disebutkan bersama penanda untuk memberikan informasi tambahan. Setelah selesai, pilih tombol *Selesai* untuk menyimpan Penanda Anda.
