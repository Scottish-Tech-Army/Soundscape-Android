# Создание отметок

Быстрее всего создать отметку на экране *Отметки*: нажмите кнопку *Создать* в правом верхнем углу экрана, затем выберите *Текущее место* или место в одной из категорий *Места рядом*. Также можно сохранить любое место, найденное с главного экрана, — через строку поиска, кнопку *Места рядом* или кнопку *Текущее место*. Выбор места открывает экран *Сведения о местоположении*, где нужно нажать кнопку *Сохранить как отметку*.

Теперь вы сможете настроить эту отметку. Можно изменить её название и добавить аннотацию, которая будет озвучиваться вместе с отметкой, чтобы дать дополнительную информацию. Когда закончите, нажмите кнопку *«Готово»*, чтобы сохранить отметку.
