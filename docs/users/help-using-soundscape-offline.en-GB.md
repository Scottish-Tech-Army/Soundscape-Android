# Using Soundscape Offline

## Using Soundscape Offline

Soundscape normally downloads map data as you move. Without an internet connection it cannot do that. To keep everything working, download an offline map before you travel.

## Downloading an offline map

1. Open the menu and select *Offline maps*.

2. Select a map from *Nearby offline maps*.

3. Select *Download offline map*.

Maps can be large, so use Wi-Fi if you can.

## Without an offline map

Callouts may still work in places you visited recently, because your phone keeps some map data for a while. Search finds only your markers. Everything returns to normal when your phone is back online.
