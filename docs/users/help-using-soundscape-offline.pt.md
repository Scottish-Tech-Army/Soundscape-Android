# Utilizar o Soundscape Offline

## Utilizar o Soundscape Offline

Normalmente, o Soundscape transfere os dados do mapa à medida que se desloca. Sem ligação à Internet não o consegue fazer. Para que tudo continue a funcionar, transfira um mapa offline antes de viajar.

## Transferir um mapa offline

1. Abra o menu e selecione *Mapas offline*.

2. Selecione um mapa em *Mapas offline nas proximidades*.

3. Selecione *Transferir mapa offline*.

Os mapas podem ser grandes, por isso use Wi-Fi se puder.

## Sem um mapa offline

Os avisos podem continuar a funcionar em locais onde esteve há pouco tempo, porque o telemóvel guarda alguns dados do mapa durante algum tempo. A pesquisa encontra apenas os seus marcos. Tudo volta ao normal quando o telemóvel estiver de novo online.
