# میرے آگے

## یہ کیا ہے؟

*\"میرے آگے\"* بٹن آپ کو آپ کے آگے موجود پانچ چیزوں تک کے بارے میں بتاتا ہے۔ *\"میرے آگے\"* کا مقصد آپ کو کسی نئے علاقے کے بارے میں سیکھتے وقت اپنے آگے کے راستے کو دریافت کرنے میں مدد دینا ہے۔

## میں اسے کب استعمال کروں گا؟

جب آپ سڑک پر چل رہے ہوں، تو آگے سڑک کے دونوں اطراف آنے والی جگہوں اور چیزوں کو دریافت کرنے کے لیے *میرے آگے* استعمال کر کے دیکھیں۔

## یہ کیسے کام کرتا ہے؟

ہوم اسکرین کے نیچے موجود تمام چار بٹنوں کی طرح، *میرے آگے* بٹن دبانے سے پہلے اپنے فون کو چپٹا (آسمان کی طرف رخ کیے ہوئے) پکڑیں اور فون کا اوپری حصہ اسی سمت میں رکھیں جس طرف آپ کا رخ ہے۔ یہ ایک کمپاس کی طرح کام کرتا ہے جو ایپ کو بتاتا ہے کہ آپ کس سمت کا رخ کیے ہوئے ہیں۔ بس *میرے آگے* بٹن پر ٹیپ کریں اور آپ اپنے تقریباً آگے موجود کئی دلچسپی کے مقامات کے بارے میں سنیں گے۔
