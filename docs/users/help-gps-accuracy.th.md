# ความแม่นยำของ GPS

## ความแม่นยำของ GPS

Soundscape อธิบายสภาพแวดล้อมรอบตัวคุณได้แม่นยำเท่ากับที่โทรศัพท์ของคุณรู้ว่าคุณอยู่ที่ไหนเท่านั้น ความแม่นยำ 10 เมตร (30 ฟุต) หรือดีกว่าถือว่าดี ไม่เกิน 20 เมตร (60 ฟุต) ถือว่าพอใช้ได้ และหากมากกว่านั้น การแจ้งเตือนอาจบอกฝั่งถนนผิดหรือมาช้า

โดยปกติความแม่นยำจะแย่ที่สุดเมื่ออยู่ในอาคาร ท่ามกลางอาคารสูง และในช่วงประมาณนาทีแรกหลังจากออกไปข้างนอก หากตัวเลขด้านล่างยังคงแย่อยู่ขณะที่คุณอยู่กลางแจ้งในที่โล่ง ลองปิดบริการตำแหน่งที่ตั้งของโทรศัพท์แล้วเปิดใหม่อีกครั้ง

ความแม่นยำปัจจุบัน: %1$s (%2$s)
