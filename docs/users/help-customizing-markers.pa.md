# ਮਾਰਕਰਾਂ ਨੂੰ ਆਪਣੇ ਮੁਤਾਬਕ ਬਣਾਉਣਾ

ਜੇ ਤੁਸੀਂ ਪਹਿਲਾਂ ਬਣਾਏ ਮਾਰਕਰ ਦਾ ਨਾਮ ਬਦਲਣਾ ਜਾਂ ਉਸ ਵਿੱਚ ਨੋਟ ਜੋੜਨਾ ਚਾਹੁੰਦੇ ਹੋ, ਤਾਂ *ਮਾਰਕਰ ਅਤੇ ਰੂਟ* ਪੰਨੇ ਦੀ *ਮਾਰਕਰ* ਟੈਬ ਤੋਂ ਮਾਰਕਰ ਚੁਣੋ, ਅਤੇ ਫਿਰ *ਮਾਰਕਰ ਸੋਧੋ* ਬਟਨ ਚੁਣੋ। ਇਸ ਨਾਲ ਤੁਸੀਂ ਮਾਰਕਰਾਂ ਨੂੰ ਵਰਣਨਯੋਗ ਜਾਂ ਲਾਭਦਾਇਕ ਛੋਟੇ ਨਾਮ ਦੇ ਸਕਦੇ ਹੋ, ਅਤੇ ਨੋਟ ਵਾਲੇ ਖਾਨੇ ਨਾਲ ਲੰਮਾ ਵਰਣਨ ਵੀ ਦੇ ਸਕਦੇ ਹੋ।

ਜੇ ਤੁਹਾਨੂੰ ਹੁਣ ਕਿਸੇ ਮਾਰਕਰ ਦੀ ਲੋੜ ਨਹੀਂ, ਤਾਂ ਇਸ *ਮਾਰਕਰ ਸੋਧੋ* ਸਕ੍ਰੀਨ ਤੋਂ ਤੁਸੀਂ ਉਸਨੂੰ ਮਿਟਾ ਵੀ ਸਕਦੇ ਹੋ।
