# 离线使用 Soundscape

## 离线使用 Soundscape

Soundscape 通常会在您移动时下载地图数据。没有网络连接时就无法下载。为了让一切照常工作，请在出行前下载离线地图。

## 下载离线地图

1. 打开菜单并选择*离线地图*。

2. 从*附近的离线地图*中选择一张地图。

3. 选择*下载离线地图*。

地图可能很大，请尽量使用 Wi-Fi。

## 没有离线地图时

在您最近去过的地方，提示可能仍然有效，因为手机会把一部分地图数据保留一段时间。搜索只能找到您的标记点。手机重新联网后，一切都会恢复正常。
