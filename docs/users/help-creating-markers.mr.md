# मार्कर तयार करणे

मार्कर तयार करण्याचा सर्वात जलद मार्ग म्हणजे *मार्कर* स्क्रीन: स्क्रीनच्या वरच्या उजव्या कोपऱ्यातील *नवीन* बटण निवडा, नंतर *सध्याचे स्थान* किंवा *जवळपासची ठिकाणे* मधील एखाद्या श्रेणीतील ठिकाण निवडा. मुख्य स्क्रीनवरून सापडलेले कोणतेही ठिकाणही तुम्ही शोध बार, *जवळपासची ठिकाणे* बटण किंवा *सध्याचे स्थान* बटण वापरून जतन करू शकता. एखादे ठिकाण निवडल्यावर तुम्ही *स्थान तपशील* स्क्रीनवर जाता, जिथे तुम्ही *मार्कर म्हणून जतन करा* बटण निवडता.

आता तुम्हाला हे मार्कर सानुकूलित करण्याचा पर्याय मिळेल. तुम्ही मार्करचे नाव बदलू शकता, आणि अतिरिक्त माहिती देण्यासाठी मार्करसोबत सांगितली जाणारी एक टिप्पणीही जोडू शकता. पूर्ण झाल्यावर, तुमचे मार्कर जतन करण्यासाठी *पूर्ण झाले* बटण निवडा.
