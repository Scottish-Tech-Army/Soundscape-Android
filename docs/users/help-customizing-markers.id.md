# Menyesuaikan Penanda

Jika Anda ingin mengganti nama penanda yang sebelumnya Anda buat, atau menambahkan anotasi padanya, pilih penanda tersebut di layar *Penanda*, lalu pilih tombol *Edit Penanda*. Anda dapat menggunakan ini untuk memberi penanda julukan yang deskriptif atau berguna, serta memberi deskripsi yang lebih panjang menggunakan kolom anotasi.

Dari layar *Edit Penanda* ini, Anda juga dapat menghapus penanda jika sudah tidak diperlukan lagi.
