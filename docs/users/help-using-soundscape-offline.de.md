# Soundscape offline verwenden

## Soundscape offline verwenden

Normalerweise lädt Soundscape Kartendaten herunter, während Sie unterwegs sind. Ohne Internetverbindung geht das nicht. Damit alles weiter funktioniert, laden Sie vor der Reise eine Offline-Karte herunter.

## Offline-Karte herunterladen

1. Öffnen Sie das Menü und wählen Sie *Offline-Karten*.

2. Wählen Sie eine Karte unter *Offline-Karten in der Nähe*.

3. Wählen Sie *Offline-Karte herunterladen*.

Karten können groß sein. Nutzen Sie daher möglichst WLAN.

## Ohne Offline-Karte

Hinweise funktionieren vielleicht noch an Orten, an denen Sie vor Kurzem waren, weil Ihr Telefon einige Kartendaten eine Zeit lang behält. Die Suche findet nur Ihre Markierungen. Sobald Ihr Telefon wieder online ist, funktioniert alles wie gewohnt.
