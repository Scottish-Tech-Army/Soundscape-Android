# 내 위치

*내 위치*는 지금 어디에 있는지 알려 줍니다. 바라보는 방향이나 이동 방향을 말한 다음, 지금 있는 도로나 주소를 말합니다. 버스에서 내렸을 때, 건물에서 나왔을 때, 방향을 잃었을 때 사용하세요.

멈춰 서 있다면 먼저 휴대폰의 위쪽 끝이 바라보는 방향을 향하게 하세요. 휴대폰이 잠겨 있거나 Soundscape가 화면에 없으면 휴대폰을 수평으로도 들어 주세요.
