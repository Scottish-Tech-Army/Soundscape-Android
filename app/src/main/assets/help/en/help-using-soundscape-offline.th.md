# การใช้ Soundscape แบบออฟไลน์

## การใช้ Soundscape แบบออฟไลน์

ปกติแล้ว Soundscape จะดาวน์โหลดข้อมูลแผนที่ขณะที่คุณเคลื่อนที่ หากไม่มีการเชื่อมต่ออินเทอร์เน็ตก็จะทำเช่นนั้นไม่ได้ เพื่อให้ทุกอย่างยังใช้งานได้ ให้ดาวน์โหลดแผนที่ออฟไลน์ก่อนออกเดินทาง

## การดาวน์โหลดแผนที่ออฟไลน์

1. เปิดเมนูแล้วเลือก *แผนที่ออฟไลน์*

2. เลือกแผนที่จาก *แผนที่ออฟไลน์ใกล้เคียง*

3. เลือก *ดาวน์โหลดแผนที่ออฟไลน์*

แผนที่อาจมีขนาดใหญ่ จึงควรใช้ Wi-Fi หากทำได้

## เมื่อไม่มีแผนที่ออฟไลน์

การแจ้งเตือนอาจยังใช้งานได้ในที่ที่คุณเพิ่งไปมา เพราะโทรศัพท์เก็บข้อมูลแผนที่บางส่วนไว้ระยะหนึ่ง การค้นหาจะพบเฉพาะหมุดของคุณ ทุกอย่างจะกลับเป็นปกติเมื่อโทรศัพท์ออนไลน์อีกครั้ง
