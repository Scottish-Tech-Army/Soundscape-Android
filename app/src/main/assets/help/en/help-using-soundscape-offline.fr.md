# Utiliser Soundscape hors ligne

## Utiliser Soundscape hors ligne

Soundscape télécharge normalement les données cartographiques au fil de vos déplacements. Sans connexion Internet, il ne peut pas le faire. Pour que tout continue de fonctionner, téléchargez une carte hors ligne avant de partir.

## Télécharger une carte hors ligne

1. Ouvrez le menu et sélectionnez *Cartes hors ligne*.

2. Sélectionnez une carte dans *Cartes hors ligne à proximité*.

3. Sélectionnez *Télécharger la carte hors ligne*.

Les cartes peuvent être volumineuses. Utilisez le Wi-Fi si possible.

## Sans carte hors ligne

Les annonces peuvent encore fonctionner dans les lieux que vous avez visités récemment, car votre téléphone garde certaines données cartographiques pendant un moment. La recherche ne trouve que vos marqueurs. Tout redevient normal quand votre téléphone est de nouveau en ligne.
