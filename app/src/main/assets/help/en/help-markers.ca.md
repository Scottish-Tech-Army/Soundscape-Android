# Marcadors

Un marcador és un lloc que has desat. Pot ser qualsevol lloc que t'importi: casa teva, una parada d'autobús, l'entrada d'un edifici o un pas de vianants.

Soundscape anuncia els teus marcadors quan hi passes a prop. Pots posar una balisa sonora en un marcador, afegir-lo a una ruta o sentir els més propers amb el botó *Marcadors propers*.

## Crear marcadors

1. Selecciona *Marcadors* a la pantalla principal i després selecciona *Nou*.

2. Tria *Ubicació actual*, o un lloc de *Llocs propers*.

3. Canvia el nom si vols i afegeix-hi notes. Soundscape llegeix les notes juntament amb el marcador.

4. Selecciona *Fet*.

També pots desar qualsevol lloc que trobis. Obre els seus *Detalls de la ubicació* i selecciona *Desa com a marcador*.

## Personalitzar marcadors

Selecciona el marcador a la pantalla *Marcadors* i després selecciona *Edita el marcador*. Pots canviar-ne el nom, les notes i la posició, o seleccionar *Suprimeix el marcador*. Suprimir un marcador també el treu de les teves rutes.
