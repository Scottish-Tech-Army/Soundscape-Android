# Menggunakan Soundscape Secara Offline

## Menggunakan Soundscape Secara Offline

Soundscape biasanya mengunduh data peta saat Anda bergerak. Tanpa koneksi internet, hal itu tidak bisa dilakukan. Agar semuanya tetap berfungsi, unduh peta offline sebelum Anda bepergian.

## Mengunduh peta offline

1. Buka menu dan pilih *Peta offline*.

2. Pilih peta dari *Peta offline di sekitar*.

3. Pilih *Unduh peta offline*.

Ukuran peta bisa besar, jadi gunakan Wi-Fi jika bisa.

## Tanpa peta offline

Pemberitahuan mungkin masih berfungsi di tempat yang baru-baru ini Anda kunjungi, karena ponsel menyimpan sebagian data peta untuk sementara. Pencarian hanya menemukan penanda Anda. Semuanya kembali normal saat ponsel Anda kembali online.
