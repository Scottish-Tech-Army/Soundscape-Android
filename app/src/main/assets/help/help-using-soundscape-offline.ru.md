# Использование Soundscape без интернета

## Использование Soundscape без интернета

Обычно Soundscape загружает данные карты по мере вашего движения. Без подключения к интернету это невозможно. Чтобы всё продолжало работать, загрузите офлайн-карту перед поездкой.

## Загрузка офлайн-карты

1. Откройте меню и выберите *Офлайн‑карты*.

2. Выберите карту в разделе *Ближайшие офлайн‑карты*.

3. Выберите *Загрузить офлайн-карту*.

Карты могут быть большими, поэтому по возможности используйте Wi-Fi.

## Без офлайн-карты

Уточнения могут по-прежнему работать в местах, где вы недавно побывали, потому что телефон какое-то время хранит часть данных карты. Поиск находит только ваши отметки. Всё вернётся в норму, когда телефон снова будет в сети.
