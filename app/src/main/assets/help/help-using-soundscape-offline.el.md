# Χρήση του Soundscape εκτός σύνδεσης

## Χρήση του Soundscape εκτός σύνδεσης

Το Soundscape συνήθως κατεβάζει δεδομένα χάρτη καθώς μετακινείστε. Χωρίς σύνδεση στο διαδίκτυο δεν μπορεί να το κάνει. Για να συνεχίσουν όλα να λειτουργούν, κατεβάστε έναν χάρτη εκτός σύνδεσης πριν ταξιδέψετε.

## Λήψη χάρτη εκτός σύνδεσης

1. Ανοίξτε το μενού και επιλέξτε *Χάρτες εκτός σύνδεσης*.

2. Επιλέξτε έναν χάρτη από το *Κοντινοί χάρτες εκτός σύνδεσης*.

3. Επιλέξτε *Λήψη χάρτη εκτός σύνδεσης*.

Οι χάρτες μπορεί να είναι μεγάλοι, γι’ αυτό χρησιμοποιήστε Wi-Fi αν μπορείτε.

## Χωρίς χάρτη εκτός σύνδεσης

Οι επεξηγήσεις μπορεί να λειτουργούν ακόμη σε μέρη που επισκεφθήκατε πρόσφατα, επειδή το τηλέφωνό σας κρατά ορισμένα δεδομένα χάρτη για λίγο. Η αναζήτηση βρίσκει μόνο τους δείκτες σας. Όλα επανέρχονται στο κανονικό όταν το τηλέφωνό σας συνδεθεί ξανά.
