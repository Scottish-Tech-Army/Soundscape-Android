# Lokasi Saya

*Lokasi Saya* memberi tahu di mana Anda berada. Tombol ini menyebutkan arah hadap atau arah perjalanan Anda, lalu jalan atau alamat tempat Anda berada. Gunakan saat Anda turun dari bus, keluar dari gedung, atau kehilangan arah.

Jika Anda berdiri diam, arahkan dulu bagian atas ponsel ke arah hadap Anda. Jika ponsel terkunci, atau Soundscape tidak ada di layar, pegang juga ponsel secara mendatar.
