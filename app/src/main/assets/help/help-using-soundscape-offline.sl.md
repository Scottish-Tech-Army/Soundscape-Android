# Uporaba aplikacije Soundscape brez povezave

## Uporaba aplikacije Soundscape brez povezave

Soundscape običajno prenaša podatke zemljevida med vašim gibanjem. Brez internetne povezave tega ne more. Da bo vse delovalo naprej, pred potjo prenesite zemljevid brez povezave.

## Prenos zemljevida brez povezave

1. Odprite meni in izberite *Zemljevidi brez povezave*.

2. Izberite zemljevid v razdelku *Zemljevidi brez povezave v bližini*.

3. Izberite *Prenesi zemljevid brez povezave*.

Zemljevidi so lahko veliki, zato po možnosti uporabite Wi-Fi.

## Brez zemljevida brez povezave

Zvočna obvestila morda še delujejo na krajih, ki ste jih nedavno obiskali, ker telefon nekaj časa hrani del podatkov zemljevida. Iskanje najde samo vaše oznake. Vse se vrne v običajno stanje, ko je telefon spet povezan.
