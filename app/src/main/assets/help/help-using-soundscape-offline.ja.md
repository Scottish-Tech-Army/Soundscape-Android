# Soundscape をオフラインで使う

## Soundscape をオフラインで使う

Soundscape は通常、移動に合わせて地図データをダウンロードします。インターネットに接続していないと、それができません。すべての機能を使い続けられるように、出かける前にオフラインマップをダウンロードしてください。

## オフラインマップをダウンロードする

1. メニューを開いて *オフラインマップ* を選択します。

2. *近くのオフラインマップ* から地図を選択します。

3. *オフラインマップをダウンロードする* を選択します。

地図は大きいことがあるので、できれば Wi-Fi を使ってください。

## オフラインマップがない場合

最近訪れた場所では、コールアウトが引き続き動作することがあります。スマートフォンが一部の地図データをしばらく保持しているためです。検索で見つかるのは自分のマーカーだけです。スマートフォンがオンラインに戻ると、すべて元どおりになります。
