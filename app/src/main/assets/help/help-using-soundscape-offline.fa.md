# استفاده‌ی آفلاین از ساند‌اسکیپ

## استفاده‌ی آفلاین از ساند‌اسکیپ

ساند‌اسکیپ معمولاً داده‌های نقشه را هنگام حرکت شما دانلود می‌کند. بدون اتصال اینترنت نمی‌تواند این کار را انجام دهد. برای اینکه همه‌چیز همچنان کار کند، پیش از سفر یک نقشه‌ی آفلاین دانلود کنید.

## دانلود نقشه‌ی آفلاین

1. منو را باز کنید و *نقشه‌های آفلاین* را انتخاب کنید.

2. از *نقشه‌های آفلاین نزدیک* یک نقشه را انتخاب کنید.

3. *دانلود نقشه‌ی آفلاین* را انتخاب کنید.

نقشه‌ها ممکن است حجیم باشند، پس اگر می‌توانید از Wi-Fi استفاده کنید.

## بدون نقشه‌ی آفلاین

اعلان‌ها ممکن است در جاهایی که به‌تازگی رفته‌اید همچنان کار کنند، چون گوشی بخشی از داده‌های نقشه را مدتی نگه می‌دارد. جستجو فقط نشانه‌های شما را پیدا می‌کند. وقتی گوشی دوباره آنلاین شود، همه‌چیز به حالت عادی برمی‌گردد.
